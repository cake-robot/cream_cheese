Spoiler settings
Manual controls for what's spoiler-protected -- nothing here changes on its own. The Slate is the one page that still shows protected games (ranked by watchability, numbers withheld). Everywhere else, a protected game is left off the list entirely.
Default
Every game from this point in the season calendar onward is protected -- a later season entirely, or this season from the chosen week on -- unless a week or game override below says otherwise. This is what you'd move forward mid-season (e.g. "I don't care about being spoiled for week 1 anymore").
Hide from onward
Week overrides
Beats the default, in either direction, for one (season, type, week).
Game overrides
Beats both the default and any week override, for one specific game -- the strongest tier. Games tab search excludes protected games, so search here instead; it deliberately doesn't.
